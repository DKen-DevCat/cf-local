### REV-8 (commit `4a99a69`)

- [x] **REV-8**: `ci.yml` nginx :8080 wait の `curl -fsS` 誤用を code= パターン (`curl -s -w "%{http_code}"` + `[ "$code" != "000" ]`) に統一。コメント「200 でなくとも応答すれば up」の意図通り 5xx を「応答した」とみなして break 到達。CI runner で origin :3000 が居ないため 502 になり、REV-3 の `exit 1` 厳格化が顕在化させた既存バグの修正

検証: `go vet ./...` PASS / `gofmt -l .` 空 / `go test ./internal/...` 10s PASS / reloader test 適用前 14/20 → 適用後 20/20 で flake 撲滅 / CI 全ジョブ緑
